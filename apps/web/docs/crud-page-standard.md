# CRUD 页面统一标准

适用范围：所有新建列表页、列表型业务页。

## 必须满足

- 页面容器必须使用 `BaseCrudPage`。
- 槽位结构必须包含：`#search`、`#actions-left`、`#actions-right`、`#data`、`#pager-right`。
- 表格组件必须使用：`NDataTable` + `class="crud-table-flat"`。
- 列配置必须接入：`TableColumnManager` + `useColumnConfig`。
- 列标题必须使用 `createDraggableTitle`，保证支持拖拽排序。
- 业务列必须提供 `sorter`，比较函数统一使用 `compareSortValue`。
- 列宽处理必须通过 `withResizable`，保证可拖拽调整宽度。
- 页面初始化必须先调用 `loadColumnSettings()`，再执行首次查询。
- 列可见性变更必须使用 `handleVisibleChange`，并保留“至少一列可见”提示。
- 新增类按钮必须放在 `#actions-left`，按钮文案统一为 `新增`（不使用 `+` 等符号）。
- 页面主列表第一列必须为选择列，并接入 `useTableSelection`。点击行执行单选，复选框保留多选能力，双击行进入查看。
- 页面主列表禁止使用标题为“操作”、键为 `action` / `actions` 的操作列，也禁止把查看、编辑、删除和业务执行按钮放进行内。
- 主业务按钮必须放在 `#actions-left`，顺序统一为：`新增 → 查看 → 编辑 → 业务动作 → 删除/取消 → 刷新`。
- 单行操作仅在恰好选中一行且状态允许时启用；批量按钮仅在接口明确支持批量操作时允许多选。
- 按钮在状态不允许时保持显示并禁用，不得通过条件渲染造成按钮区跳动。
- `#actions-right` 仅用于列配置、视图切换和表格显示工具。
- 明细子表、库存分配表和选择弹窗中的局部操作列不受主列表限制。
- 搜索区按钮必须固定在右侧：使用 `crud-page-spacer` 将按钮推到右边，并且统一保留 `查询` + `重置` 两个按钮。
- 搜索区的 `查询`、`重置`以及工具栏的刷新、查看、编辑、选择、下载、返回均使用中性按钮，不得配置 `type="primary"`。
- 主题色实心按钮只用于新增、保存、提交、开始、完成等写入或推进流程的主操作；同一个可见操作组最多保留一个实心主题色按钮。
- 菜单、标签、分页、选中数量和表格鼠标选中态使用中性色；危险操作继续使用错误色，业务状态统一使用状态令牌。
- 搜索区结构优先使用 `n-form inline + class="crud-search-form"`，避免与 `crud-search-row` 混用导致视觉高度不一致。
- 折叠按钮必须位于搜索区最底部中线；折叠后仅保留一条分隔线高度（不保留额外内容区高度）。
- 搜索控件像素规则：输入/选择/数字/日期控件最小宽度统一为 `180px`。
- 搜索按钮像素规则：按钮最小宽度统一为 `72px`。
- 状态、业务类型、任务类型、事务类型、同步状态、执行结果和布尔语义字段必须使用 `WmsStatusTag`，不得直接配置 `NTag` 外观。
- `WmsStatusTag` 统一为无边框、圆角、低饱和背景；页面只提供 `label` 和语义 `type`，不得覆盖背景色、边框、圆角或字体。
- 已选数量、计数、看板数量和临时提示等功能标签可继续使用 `NTag`。

## 页面改造清单

新建或改造页面时，提交前逐项确认：

- 已使用 `BaseCrudPage` 标准槽位布局
- 已接入 `TableColumnManager`
- 已接入 `useColumnConfig`
- 搜索区右侧已包含 `查询` 与 `重置` 按钮
- 查询、重置、刷新、查看、编辑、选择、下载和返回按钮均未使用主题色
- 每个可见操作组最多保留一个主题色实心主按钮
- 搜索区按钮通过 `crud-page-spacer` 固定在右侧
- 搜索区控件最小宽度已遵循 `180px` 规则
- 搜索区按钮最小宽度已遵循 `72px` 规则
- 折叠后搜索区仅保留底部分隔线高度
- 新增按钮位于左侧，文案为 `新增`
- 主列表第一列为选择列，并支持点击行单选、复选框多选和双击查看
- 主列表不存在“操作”列或行内业务按钮
- 顶部按钮顺序符合“新增、查看、编辑、业务动作、删除/取消、刷新”
- 状态不允许时按钮保持显示但禁用
- 业务语义字段已使用 `WmsStatusTag`，同一业务值在不同页面的颜色一致
- 明细子表中的局部操作未被误迁移到页面顶部
- 所有可展示字段都支持排序
- 列标题可拖拽重排
- 表格样式类已统一为 `crud-table-flat`
- CRUD 规范检查通过：`npm run check:crud`
- 业务语义标签规范检查通过：`npm run check:semantic-tags`
- 主题色使用规范检查通过：`npm run check:theme-accent`
- 本地构建通过：`npm run build`
